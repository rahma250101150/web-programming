Assignment 1 - Introduction to the Internet & Web

1. Internet vs World Wide Web

The Internet is a global infrastructure of connected devices using TCP/IP. The World Wide Web is an information service built on top of the Internet that uses HTTP/HTTPS to access web pages.

2. Web 3.0 Summary

Web 3.0 is a decentralized web powered by Blockchain, Smart Contracts, and dApps, placing data ownership back in the hands of users.
